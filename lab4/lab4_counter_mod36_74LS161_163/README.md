# lab4_counter_mod36_74LS161_163

**十进制模 36 加法计数器**（第 4 次实验 2.1.7 节 4b）

一片 74LS163 做个位（0～9），一片 74LS161 做十位（0～3），两片共用同一个时钟，
计数值 00～35，满 36 回 00。

板载 50MHz 经 24 位分频到约 3Hz 作为计数时钟，**自动走位**，一圈约 12 秒。

- Device: Pango Logos **PGL22G** / speed grade **-6** / package **MBG324**
- Top module: `counter_mod36`
- Project file: `lab4_counter_mod36_74LS161_163.pds`
- 芯片：74LS163 ×1 + 74LS161 ×1 + 74LS20 ×1 + 74LS00 ×1

## 端口与引脚

| Port | 含义 | Dir | Pin | 灯位 |
|------|------|-----|-----|------|
| `clk` | 50MHz 全局时钟 | input | `J18` | — |
| `rst` | 复位，置 1 时清零到 00 | input | `J14` | — |
| `t1` | 十位 bit1（权 2） | output | `F14` | LED1 |
| `t0` | 十位 bit0（权 1） | output | `F13` | LED2 |
| `u3` | 个位 bit3（权 8） | output | `F16` | LED3 |
| `u2` | 个位 bit2（权 4） | output | `G16` | LED4 |
| `u1` | 个位 bit1（权 2） | output | `H16` | LED5 |
| `u0` | 个位 bit0（权 1） | output | `J16` | LED6 |

LED1～LED6 从左到右依次是 `t1 t0 u3 u2 u1 u0`，即**先十位（2 位）再个位（4 位）**。

## 设计说明

### 一、时钟

```
div 是 24 位自由计数器，cp = div[23]，50MHz ÷ 2^24 ≈ 3Hz
```

两片计数器的 `CLK` 都接 `cp`。36 个状态 × 0.33 秒 ≈ 12 秒走完一圈。

### 二、分工与级联

| 芯片 | 角色 | 计数范围 | 用到的控制端 |
|---|---|---|---|
| 74LS163（U_UNIT） | 个位 | 0～9（模 10） | `Clear`（同步清零）、`Load` |
| 74LS161（U_TENS） | 十位 | 0～3 | `Load`、`ENP`/`ENT` |

两片 `CLK` 都接 `cp`，属于**同步级联**（不是用进位端去当时钟）。

### 三、个位：模 10（163 的同步清零）

```
clear_u_n = NAND4(u3, ~u2, ~u1, u0)      // 仅当 u = 1001 (9) 时为 0
```

163 是**同步清零**：`Clear = 0` 要等下一个 `cp` 上升沿才清零。
所以检测到 9 之后再来一个时钟，个位正好从 9 回到 0，共 10 个状态。
（换成 161 的异步清零，检测到 9 就会立刻变 0，只能数到 9 个状态。）

### 四、复位

`rst` 接 J14，置 1 时把两片计数器一起清 0：

```
U_UNIT.Clear = clear_u_n & ~rst      （163 的 Clear 低有效，要用"与"把两个清零条件合起来）
U_TENS.Clear = ~rst                   （161 的 Clear 直接接 ~rst）
```

`rst` 优先级高于计数和置数，拨 1 立刻回到 `00`。

### 五、进位

```
carry = ~clear_u_n                        // 即 u == 9
```

`carry` 接 161 的 `ENP` 和 `ENT`，因此在个位 9→0 那一个时钟沿，十位同时加 1。

### 六、满 36 归零（置数法）

```
load_n = NAND4(t1, t0, u2, u0)           // 仅当十位 = 3 且个位 = 5（即 35）时为 0
```

检测到末态 35 后，下一个时钟沿把两片**同时**同步装入 `0000`，于是 35 → 00，
整个循环正好 36 个状态，不会出现异步清零那种瞬时毛刺。

> `load_n` 只用 4 个正逻辑输入就能唯一确定 35：十位最大就是 3，`t1·t0` 已经等价于"十位=3"；
> 个位在 0～5 之间取值时，`u2·u0` 只在 5 这个点上成立。

### 七、门级资源

| 芯片 | 用途 | 用门 |
|---|---|---|
| `74LS20` ×1 | `clear_u_n`、`load_n` 两个 4 输入与非 | 2 / 2 |
| `74LS00` ×1 | `~u2`、`~u1`、`carry` 三个反相器 | 3 / 4 |

74LS00 第 4 个门输入已接地。

## 计数序列（节选）

| 状态 | t1 t0 | u3 u2 u1 u0 |
|:---:|:---:|:---:|
| 00 | 0 0 | 0 0 0 0 |
| 09 | 0 0 | 1 0 0 1 |
| 10 | 0 1 | 0 0 0 0 |
| 19 | 0 1 | 1 0 0 1 |
| 29 | 1 0 | 1 0 0 1 |
| 35 | 1 1 | 0 1 0 1 |
| 00 | 0 0 | 0 0 0 0 |

个位永远只出现 `0000`～`1001`，十位永远只出现 `00`～`11`。

## 时钟约束

`clk` 接 `J18`，是真正的全局时钟脚，fdc 末尾有 `create_clock -period 20.000`（50MHz）。
`cp` 由寄存器驱动，PDS 可能给出"非专用时钟网络"提示（`C:` 级），属预期现象。
