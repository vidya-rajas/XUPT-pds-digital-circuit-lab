# lab4_counter_mod36_74LS161_163 实验使用说明

十进制模 36 计数器：00 数到 35 再回 00，**自动走位**（约 3Hz，一圈约 12 秒）。

- 工程文件：`lab4_counter_mod36_74LS161_163.pds`
- 顶层模块：`counter_mod36`（源码 `rtl/counter_mod36.v`）
- 芯片：74LS163 ×1 + 74LS161 ×1 + 74LS20 ×1 + 74LS00 ×1
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. 打开 PDS → File → Open Project → 选本目录的 `lab4_counter_mod36_74LS161_163.pds`。
2. Design Flow：Compile → Synthesize → Device Map → Place & Route → Generate Bitstream。
3. 下载 `generate_bitstream/counter_mod36.sbit`。

## 二、开关与灯

| 板载 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| 时钟 50MHz | `J18` | `clk` | 板载晶振，**不用接线** |
| 开关 SW2（左起第 2 个） | `J14` | `rst` | 复位，拨 1 清零到 00 |

本工程只有 ``rst`` 一个开关，其余开关无效。

| 灯位 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| LED1（最左） | `F14` | `t1` | 十位权 2 |
| LED2 | `F13` | `t0` | 十位权 1 |
| LED3 | `F16` | `u3` | 个位权 8 |
| LED4 | `G16` | `u2` | 个位权 4 |
| LED5 | `H16` | `u1` | 个位权 2 |
| LED6 | `J16` | `u0` | 个位权 1 |

左起前两颗是**十位**，后四颗是**个位**。LED7、LED8 没有约束。

## 三、操作与现象

上电即从 00 开始自动加 1，每 1 秒一个数，36 个数一圈 36 秒。

| 十进制 | t1 t0 | u3 u2 u1 u0 | 灯（LED1~LED6） |
|:---:|:---:|:---:|:---:|
| 00 | 0 0 | 0 0 0 0 | ○○○○○○ |
| 09 | 0 0 | 1 0 0 1 | ○○●○○● |
| 10 | 0 1 | 0 0 0 0 | ○●○○○○ |
| 20 | 1 0 | 0 0 0 0 | ●○○○○○ |
| 35 | 1 1 | 0 1 0 1 | ●●○●○● |
| 00 | 0 0 | 0 0 0 0 | ○○○○○○ |

## 四、验证清单

- [ ] `rst=1` 时六颗灯全灭（显示 00），拨回 0 后自动开始
- [ ] 09 之后变 10（个位归 0、十位加 1）
- [ ] 29 之后变 30
- [ ] 35 之后回到 00
- [ ] 全程个位不出现 1010～1111，十位只有 00～11
- [ ] 一圈约 12 秒

## 五、注意

- **十位只有 2 位有效**，显示 35 时十位是 `11`、个位是 `0101`。
- 个位用的是 **163 的同步清零**：检测到 9 之后再等一个时钟沿才回 0，所以能数满 10 个状态。
  若换成 161（异步清零），个位会在 9 上立刻清零，只能数到 9 个状态，模 36 会变成模 33。
- 35→00 是**同步置数**，不是清零，所以不会"闪一下 36"。
- 时钟来自板载 50MHz 分频；`cp` 是内部寄存器分频出来的，PDS 可能提示"非专用时钟网络"（`C:` 级），不影响使用。
