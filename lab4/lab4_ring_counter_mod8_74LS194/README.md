# lab4_ring_counter_mod8_74LS194

**74LS194 + 7400 实现具有自启动特性的扭环计数器（模 N=8）**

由 `lab4_storage/text4.1` 的参考实现迁移而来，**引脚顺序按题目要求从头到尾反置**：
`qa→G16、qb→H16、qc→J16、qd→K18`（原来 qa 在最右，现在 qa 在最左）。

- Device: Pango Logos **PGL22G** / speed grade **-6** / package **MBG324**
- Top module: `ring_counter`
- Project file: `lab4_ring_counter_mod8_74LS194.pds`
- 芯片：74LS194 ×1 + 74LS00 ×1 + 74LS20 ×1

## 端口与引脚

| Port | 含义 | Dir | Pin | 灯位 |
|------|------|-----|-----|------|
| `clk` | 50MHz 全局时钟 | input | `J18` | — |
| `clr_n` | 清零，**低电平有效** | input | `K15` | — |
| `qa` | QA | output | `G16` | LED4 |
| `qb` | QB | output | `H16` | LED5 |
| `qc` | QC | output | `J16` | LED6 |
| `qd` | QD | output | `K18` | LED7 |

LED4～LED7 从左到右依次是 `qa qb qc qd`。

> **电平**：`LVCMOS33 / VCCIO 3.3`，与全库其余工程一致（2026-11 统一）。

## 设计说明

### 一、时钟：50MHz 分频到 1Hz

板载 `J18` 是 50MHz。直接把 50MHz 送给 194，一秒移 5000 万次，LED 只会显示"一片亮"，
肉眼看不出扭环在转。所以先用一个 24 位计数器分频：

```
cp 每 25,000,000 个时钟翻转一次   50MHz ÷ 50,000,000 = 1Hz
```

`clr_n` 同时清零分频器和 194，所以复位后从 `0000` 开始、每秒走约 3 步。

> 分频器是行为级 `reg`，属于"计数器/定时器"，不当作门电路；这是仓库里允许的写法。

### 二、扭环本体

| 74194 引脚 | 接法 |
|---|---|
| `S1S0` | 正常 `01`（右移） |
| `SR` | `~QD`（扭环反馈） |
| `SL` | 0 |
| `CLR` | `clr_n` |
| `CLK` | `cp`（分频后的 1Hz） |

有效 8 状态环：

```
0000 → 1000 → 1100 → 1110 → 1111 → 0111 → 0011 → 0001 → 0000
```

### 三、自启动（关键）

16 个状态里另外 8 个构成一个**无效闭环**：

```
0100 → 1010 → 1101 → 0110 → 1011 → 0101 → 0010 → 1001 → 0100
```

上电若落进这个环就永远出不来。这里只译出其中一个状态 `0100`：

```
illegal_n = NAND4(~qa, qb, ~qc, ~qd)        // 仅当 qa qb qc qd = 0 1 0 0 时为 0
```

译中时把方式控制端从 `01` 切成 `10`——**左移**，左移输入 `SL=0`：

```
0100 --左移--> 1000        （1000 在有效环里）
```

于是计数器在下一次时钟就被拉回有效循环，接着 `1000 → 1100 → 1110 …`。

因为无效环是一个 8 状态闭环，**任何**无效状态最多 8 个时钟就会转到 `0100`，
所以只译一个状态就够了，上电后最多 8 拍必然自启动。

> 参考实现的注释写的是"`S1S0=11` 并行置数，置入 1000"，但代码实际是 `s1=illegal, s0=~illegal`，
> 也就是 `10`（左移）。功能上是靠"左移一步正好把 0100 变成 1000"实现的，`a~d` 四个置数端根本没被用到。
> 本工程按代码的真实行为实现，注释同步更正。

### 四、门级实现

参考实现里 `illegal_n` 用的是行为级 `assign ~(~qa & qb & ~qc & ~qd)`，本工程按仓库规范改成真正的芯片：

| 芯片 | 用途 | 用门 |
|---|---|---|
| `74LS00` ×1 | `~qa`、`~qc`、`~qd`、`~illegal_n` | 4 / 4 |
| `74LS20` ×1 | 四输入与非，译出 `0100` | 1 / 2 |

`SR = ~QD` 直接复用 `qd` 的反相门，不额外占门。

## 时钟约束

`clk` 接的是 `J18`，是真正的全局时钟脚，不需要 `PAP_CLOCK_DEDICATED_ROUTE`；
fdc 末尾有 `create_clock -period 20.000`，对应 50MHz。

另外 `cp` 是由寄存器驱动的内部时钟，PDS 可能给出"非专用时钟网络"的提示（`C:` 级），
属预期现象，不影响生成比特流。
