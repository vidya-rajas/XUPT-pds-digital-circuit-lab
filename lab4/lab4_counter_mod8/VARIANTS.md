# 模 8 计数器 —— 16 种起始值副本（start0 ~ start15）

同一个电路（74LS161 反馈置数法模 8）的 16 个**起始值副本**，用来观察"起点不同、模数相同"的现象。

- 主工程：[`lab4_counter_mod8_74LS161`](lab4_counter_mod8_74LS161/README.md)（起始 5）
- 每个副本独立成工程，可单独打开、单独构建、单独下载
- 引脚、时钟、复位完全一样：`clk`=J18（50MHz 分频到 1Hz）、`rst`=J14、`q3~q0`=`H16` `J16` `K18` `N15`

## 通用规律

设起点为 `S`（0~15）：

1. **末态** `E = (S + 7) mod 16` —— 因为一共 8 个状态，最后一拍比起点大 7；
2. **末态译码**：把 `E` 写成 4 位，**为 0 的位取反**后送 74LS20 的 `NAND4`；
3. **门数**：`74LS00` 片数 = ⌈（E 中 0 的个数 + 2）/ 4⌉，"+2" 是 `~rst` 和 `~and_n`；
4. **复位**：FPGA 上电清成 `0000`，如果 `0` 落在循环里（`S=0` 或 `S≥9`）就不需要复位也能自启动，
   否则必须用 `rst` 把初值装进去。

## 几个有意思的对比

| 起点 | 现象 |
|---|---|
| `start0` | 最普通的 0~7 计数器，末态 7（`0111`），只需一个反相器 |
| `start8` | 8~15，末态全 1（`1111`），**一个反相器都不用**，74LS00 只做 `~rst` 和 `~and_n` |
| `start9` | 9~15 然后**溢出回 0**，末态是 `0000`，四位全要取反（6 个门，两片 74LS00） |
| `start15` | 15 之后**全灭**（溢出成 0），再逐个点亮到 6 跳回全亮 |
| `start5` | 主工程的起点，5~12 |
