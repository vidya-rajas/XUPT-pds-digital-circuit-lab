# lab4_counter_mod8_74LS161

**74LS161 反馈置数法实现模 N=8 加法计数器（起始状态 5）**

计数序列 `5 → 6 → 7 → 8 → 9 → 10 → 11 → 12 → 5`，共 8 个状态。
计数到末态 12 时把 `LOAD` 拉低，下一个时钟沿把初值 5 同步装入。

板载 50MHz 经 25 位分频到 1Hz 作为计数时钟，**自动走位，不用手动拨钟**。

- Device: Pango Logos **PGL22G** / speed grade **-6** / package **MBG324**
- Top module: `counter_mod8`
- Project file: `lab4_counter_mod8_74LS161.pds`
- 芯片：74LS161 ×1 + 74LS20 ×1 + 74LS00 ×1

## 端口与引脚

| Port | 含义 | Dir | Pin |
|------|------|-----|-----|
| `clk` | 50MHz 全局时钟 | input | `J18` |
| `rst` | 复位，置 1 时装入初值 5 | input | `J14` |
| `q3` | 计数输出最高位（权 8） | output | `H16`（LED5） |
| `q2` | 权 4 | output | `J16`（LED6） |
| `q1` | 权 2 | output | `K18`（LED7） |
| `q0` | 最低位（权 1） | output | `N15`（LED8） |

## 设计说明

### 一、时钟：50MHz 分频到 1Hz

```
分频器每 25,000,000 个时钟翻转一次 cp，50MHz ÷ 50,000,000 = 1Hz
```

161 的 `CLK` 接 `cp`，所以每 1 秒计一个数，8 个状态 8 秒走完一圈。

> 分频器是行为级 `reg`，属于"计数器/定时器"，按仓库约定不算门电路。

### 二、反馈置数

74LS161 的 `LOAD` 是**同步、低有效**：`LOAD = 0` 时，下一个 `cp` 上升沿把 `{D,C,B,A}` 装入。

```
末态 12 = 1100  →  LOAD_n = ~(q3·q2·~q1·~q0) = NAND4(q3, q2, ~q1, ~q0)
初态  5 = 0101  →  D=0, C=1, B=0, A=1
```

即计数值为 12 时把 `LOAD_n` 拉低，下一个时钟沿装入 `0101`，循环回到 5。

### 三、复位（为什么要加这个脚）

FPGA 上电时触发器被 GSR 清成 `0000`，而 `0000` 不在 5～12 这个循环里。
如果不管它，电路会从 0 一直数到 12 才第一次装入 5。所以加一个 `rst`：

```
LOAD_n = ~( (q3·q2·~q1·~q0) | rst )
```

`rst` 置 1 时强制装入 5，之后进入正常循环。

### 四、为什么检测 12 而不是 13

反馈置数法检测**末态**。循环是 5～12，末态是 12；在 12 上给 `LOAD=0`，下一个时钟沿正好回到 5。
若检测 13，循环就变成 5～13 共 9 个状态。

### 五、门级资源

| 芯片 | 用途 | 用门 |
|---|---|---|
| `74LS00` ×1 | `~q1`、`~q0`、`~rst`、`~and_n` 四个反相器 | 4 / 4 |
| `74LS20` ×1 | 末态检测 `det`、与复位相与 | 2 / 2 |

## 时钟约束

`clk` 接 `J18`，是真正的全局时钟脚，不需要 `PAP_CLOCK_DEDICATED_ROUTE`；
fdc 末尾有 `create_clock -period 20.000`，对应 50MHz。

`cp` 由寄存器驱动，PDS 可能给出"非专用时钟网络"的提示（`C:` 级），属预期现象。
