# lab4_counter_mod8_74LS161_start4 实验使用说明

74LS161 反馈置数法模 8 计数器：从 **4** 数到 **11** 再回到 4，**自动走位**（1Hz）。

- 工程文件：`lab4_counter_mod8_74LS161_start4.pds`
- 顶层模块：`counter_mod8_start4`（源码 `rtl/counter_mod8_start4.v`）
- 芯片：74LS161 ×1 + 74LS20 ×1 + 74LS00 ×1
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. 打开 PDS → File → Open Project → 选本目录的 `lab4_counter_mod8_74LS161_start4.pds`。
2. Design Flow：Compile → Synthesize → Device Map → Place & Route → Generate Bitstream。
3. 下载 `generate_bitstream/counter_mod8_start4.sbit`。

## 二、开关与灯

| 板载 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| 时钟 50MHz | `J18` | `clk` | 板载晶振，**不用接线** |
| 开关 SW2（左起第 2 个） | `J14` | `rst` | 复位，置 1 时装回初值 4 |

| 灯位 | 引脚 | 信号 |
|------|------|------|
| LED5 | `H16` | `q3`（权 8） |
| LED6 | `J16` | `q2`（权 4） |
| LED7 | `K18` | `q1`（权 2） |
| LED8（最右） | `N15` | `q0`（权 1） |

## 三、操作步骤

1. `rst` 拨到 **1**，四颗灯显示 `0100`（= 4）。
2. `rst` 拨回 **0**，自动计数，每 1 秒一步，8 秒一圈。

## 四、现象对照

| 十进制 | q3 q2 q1 q0 | 灯（LED5~LED8） |
|:---:|:---:|:---:|
| 复位后 | 0 1 0 0 | 4 | ○●○○ |
| 1 | 0 1 0 1 | 5 | ○●○● |
| 2 | 0 1 1 0 | 6 | ○●●○ |
| 3 | 0 1 1 1 | 7 | ○●●● |
| 4 | 1 0 0 0 | 8 | ●○○○ |
| 5 | 1 0 0 1 | 9 | ●○○● |
| 6 | 1 0 1 0 | 10 | ●○●○ |
| 7 | 1 0 1 1 | 11 | ●○●● |
| 回到 4 | 1 1 0 0 | 12 | ●●○○ |

## 五、验证清单

- [ ] `rst=1` 时显示 `0100`
- [ ] 拨回 0 后按 `4 → 5 → 6 → 7 → 8 → 9 → 10 → 11` 自动变化
- [ ] 到 11 后跳回 4
- [ ] 一圈 8 步、8 秒
- [ ] 全程不会出现起点之前 / 末态之后的数

## 六、注意

- 判据：**循环只在这 8 个数里**（4 → 5 → 6 → 7 → 8 → 9 → 10 → 11），出现别的数说明末态检测错了一位。
- 若不复位直接上电，电路会先自由计数到末态才第一次装入 4——第一步先拨 `rst`。
