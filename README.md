# 数字电路实验 —— 课程实验工程集

西安邮电大学《数字电路实验》课程的**全部实验工程** —— 2026.11 新 FPGA 模拟版，**全实验项目免费开源**。

> 仓库地址：<https://github.com/vidya-rajas/XUPT-pds-digital-circuit-lab>

每道题都做成一个可直接打开的 Pango Design Suite 工程，从 74LS 门电路一直做到大实验（综合设计），
共 **22 个设计 / 38 个工程目录**。

实验方式不是插芯片、接线：**先把每片 74LS 芯片写成 Verilog 模型，再在顶层把它们连起来，
烧进实验箱的 FPGA**，在箱体上用开关、LED、数码管测引脚、做演示。

> **丁鹏飞老师编写的教材是本课程的依据，每一步实验操作都要按教材对应章节进行。**

## 快速开始

1. PDS → **File → Open Project**，选中某工程目录下的 `<工程名>.pds`；
2. Design Flow：**Compile → Synthesize → Device Map → Place & Route → Generate Bitstream**；
3. 下载 `generate_bitstream/<功能名>.sbit` 到实验箱。

工程已带好设计与约束文件，打开即可编译，**不需要再 Add File**。

> **本仓库包含完整的构建产物**：每个工程的 `compile/`、`synthesize/`、`device_map/`、`place_route/`、
> `generate_bitstream/` 与 `*.sbit` 比特流都在仓库里，克隆后可直接下载比特流上板，也可以从零重跑流程。
`.pds` 内部用相对路径，整个 `labN/` 可以整体搬走，但不能把 `.pds` 单独挪出工程目录。

## 板子资源速查

```
开关（左→右）  K15  J14  J15  H13  H14  G13
LED （左→右）  F14  F13  F16  G16  H16  J16  K18  N15
数码管         段 A~G = M14 N15 J17 L17 L16 M13 H17，DP = L18
              位选 DIG1~4 = M16 K17 N17 N18
全局时钟       27MHz = H18      50MHz = J18
瞬时按键       G14
```

- LED **高电平点亮**；数码管**段码低电平点亮、位选低电平选通**（共阳）；
- 时序电路的时钟必须走 `H18` 或 `J18`，**不能用开关当时钟**（会报 `Place-0084`，详见 `PROJECT.md`）。
