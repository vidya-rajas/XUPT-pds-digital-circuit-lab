# lab2_bcd_detector_74LS151 实验使用说明

8421BCD 非法码检测：74LS151 八选一数据选择器。
把 1 和 0 预先接到数据输入端，用地址线选通，输出即为"该码是否非法"。

- 工程文件：`lab2_bcd_detector_74LS151.pds`
- 顶层模块：`bcd_detector`（源码 `rtl/bcd_detector.v`，门模型 `rtl/gate74LS151.v`）
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. 打开 PDS → File → Open Project → 选本目录的 `lab2_bcd_detector_74LS151.pds`。
2. Design Flow：Compile → Synthesize → Device Map → Place & Route → Generate Bitstream。
3. 下载 `generate_bitstream/bcd_detector.sbit`。

## 二、开关与灯

| 板载 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| 开关 SW3 | `J15` | `D` | BCD 最高位（权 8） |
| 开关 SW4 | `H13` | `C` | 权 4 |
| 开关 SW5 | `H14` | `B` | 权 2 |
| 开关 SW6（最右） | `G13` | `A` | 权 1 |
| LED8（最右） | `N15` | `F` | 1 = 非法码 |

拨动开关组成一个 4 位二进制数 `D C B A`。

## 三、操作与现象

8421BCD 只允许 0~9，10~15 是非法码：

| 数值 | D C B A | 含义 | F（LED8） |
|:---:|:---:|---|:---:|
| 0 ~ 7 | 0 x x x | 合法 | 灭 |
| 8 | 1 0 0 0 | 合法 | 灭 |
| 9 | 1 0 0 1 | 合法 | 灭 |
| 10 | 1 0 1 0 | **非法** | **亮** |
| 11 | 1 0 1 1 | **非法** | **亮** |
| 12 | 1 1 0 0 | **非法** | **亮** |
| 13 | 1 1 0 1 | **非法** | **亮** |
| 14 | 1 1 1 0 | **非法** | **亮** |
| 15 | 1 1 1 1 | **非法** | **亮** |

规律：**只要 D=1 且 C、B 不同时为 0，灯就亮**；A 完全不影响结果。

## 四、验证清单

- [ ] D=0，其余任意 → 灯灭（0~7 全合法）
- [ ] 1000、1001 → 灯灭（8 和 9 是合法码，最容易误判）
- [ ] 1010 ~ 1111 → 灯全亮
- [ ] 只拨 A（最右开关），灯不变化

## 五、注意

- 数据输入端的 8 个常量是 `Din = 1110_0000`，即第 5、6、7 号地址取 1；地址由 `{C,B,A}` 三个信号驱动，其中 `C` 接的是 D、`B` 接的是 C、`A` 接的是 B——对照原理图时别被名字绕晕。
- 无时钟、无复位，上电即工作。
