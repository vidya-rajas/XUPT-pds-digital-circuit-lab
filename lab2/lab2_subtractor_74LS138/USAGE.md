# lab2_subtractor_74LS138 实验使用说明

一位全减器：74LS138 3-8 译码器 + 74LS20 双 4 输入与非门。
输入 A（被减数）、B（减数）、C0（低位借位），输出 S（差）与 C1（借位）。

- 工程文件：`lab2_subtractor_74LS138.pds`
- 顶层模块：`subtractor`（源码 `rtl/subtractor.v`）
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. 打开 PDS → File → Open Project → 选本目录的 `lab2_subtractor_74LS138.pds`。
2. Design Flow：Compile → Synthesize → Device Map → Place & Route → Generate Bitstream。
3. 下载 `generate_bitstream/subtractor.sbit`。

## 二、开关与灯

| 板载 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| 开关 SW6（最右） | `G13` | `A` | 被减数 |
| 开关 SW5 | `H14` | `B` | 减数 |
| 开关 SW4 | `H13` | `C0` | 低位借位 |
| LED7 | `K18` | `S` | 差 |
| LED8（最右） | `N15` | `C1` | 借位 |

## 三、操作与现象

运算含义：`S = A - B - C0`，差取模 2，借位 C1 表示"不够减"。

| A | B | C0 | A-B-C0 | S（LED7） | C1（LED8，借位） |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 | 0 | 0 | 灭 | 灭 |
| 0 | 0 | 1 | -1 | **亮** | **亮** |
| 0 | 1 | 0 | -1 | **亮** | **亮** |
| 0 | 1 | 1 | -2 | 灭 | **亮** |
| 1 | 0 | 0 | 1 | **亮** | 灭 |
| 1 | 0 | 1 | 0 | 灭 | 灭 |
| 1 | 1 | 0 | 0 | 灭 | 灭 |
| 1 | 1 | 1 | -1 | **亮** | **亮** |

## 四、验证清单

重点验四组"被减数与减数不等"的情况，这里最能看出接线的对错：

- [ ] A=1,B=0,C0=0 → S 亮、借位灭（1-0=1）
- [ ] A=0,B=1,C0=0 → S 亮、借位亮（0-1=-1）
- [ ] A=1,B=0,C0=1 → S 灭、借位灭（1-0-1=0）
- [ ] A=0,B=1,C0=1 → S 灭、借位亮（0-1-1=-2）

> 这四组把 A 和 B 对调一下结果就不同，是检查"被减数/减数有没有接反"的唯一手段。若这四组全反，说明译码器的地址高位接反了。

## 五、注意

- 译码器输出低电平有效，`S = Σm(1,2,4,7)`、`C1 = Σm(1,2,3,7)`（最小项按 `{A,B,C0}` 排序）。
- 无时钟、无复位，上电即工作。
