# lab2_multiplier_2x2_74LS283 实验使用说明

两位二进制乘法器：用两片 74LS283 四位全加器实现 `a × b`。

- 工程文件：`lab2_multiplier_2x2_74LS283.pds`
- 顶层模块：`multiplier_2x2`（源码 `rtl/multiplier_2x2.v`，门模型 `rtl/gate74LS283.v`）
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. 打开 PDS → File → Open Project → 选本目录的 `lab2_multiplier_2x2_74LS283.pds`。
2. Design Flow：Compile → Synthesize → Device Map → Place & Route → Generate Bitstream。
3. 下载 `generate_bitstream/multiplier_2x2.sbit`。

## 二、开关与灯

| 板载 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| 开关 SW6（最右） | `G13` | `a1` | 被乘数高位（权 2） |
| 开关 SW5 | `H14` | `a0` | 被乘数低位（权 1） |
| 开关 SW4 | `H13` | `b1` | 乘数高位（权 2） |
| 开关 SW3 | `J15` | `b0` | 乘数低位（权 1） |
| LED5 | `H16` | `p3` | 乘积 bit3（最高位） |
| LED6 | `J16` | `p2` | 乘积 bit2 |
| LED7 | `K18` | `p1` | 乘积 bit1 |
| LED8（最右） | `N15` | `p0` | 乘积 bit0（最低位） |

四颗 LED 从左到右就是 `p3 p2 p1 p0`，直接按二进制读。

## 三、操作与现象

四个开关拼成两个 2 位数：`a = 2·a1 + a0`，`b = 2·b1 + b0`。

| a | b | 乘积 | p3 p2 p1 p0（LED5~LED8） |
|:---:|:---:|:---:|:---:|
| 0 | 0~3 | 0 | 灭 灭 灭 灭 |
| 1 | 1 | 1 | 灭 灭 灭 亮 |
| 1 | 2 | 2 | 灭 灭 亮 灭 |
| 1 | 3 | 3 | 灭 灭 亮 亮 |
| 2 | 2 | 4 | 灭 亮 灭 灭 |
| 2 | 3 | 6 | 灭 亮 亮 灭 |
| 3 | 2 | 6 | 灭 亮 亮 灭 |
| 3 | 3 | 9 | **亮** 灭 灭 亮 |

乘法交换，`a×b` 与 `b×a` 结果相同，可用来交叉验证。

## 四、验证清单

- [ ] 全 0 输入 → 四灯全灭
- [ ] 3×3=9 → LED5 亮、LED8 亮，中间两颗灭（**唯一会出现最高位亮的组合**）
- [ ] 2×2=4 → 只有 LED6 亮
- [ ] 1×3 与 3×1 结果一致（都是 3：LED7、LED8 亮）

> 3×3 这一组最关键：乘积 9 需要用到 `p3`，而 `p3` 来自第二片 283 的**和输出 S2**。如果这一组读成 5（0101），说明高位取错了引脚。

## 五、注意

- 两片 283 都只用到最低位输入 `A1/B1`，其余数据输入已在代码里接 0。
- 部分积相加最大是 1+1=2，高位落在**和输出的 S2**上，不是进位 `C4`（`C4` 权重 16，这里恒为 0）。
- 无时钟、无复位，上电即工作。
