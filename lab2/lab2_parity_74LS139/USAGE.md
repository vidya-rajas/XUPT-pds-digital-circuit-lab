# lab2_parity_74LS139 实验使用说明

三位奇偶校验电路：74LS139 双 2-4 译码器 + 74LS20 双 4 输入与非门 + 74LS04 反相器。
同时输出**奇校验位 S** 和**偶校验位 C1**。

- 工程文件：`lab2_parity_74LS139.pds`
- 顶层模块：`parity_checker`（源码 `rtl/parity_checker.v`）
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. 打开 PDS → File → Open Project → 选本目录的 `lab2_parity_74LS139.pds`。
2. Design Flow：Compile → Synthesize → Device Map → Place & Route → Generate Bitstream。
3. 下载 `generate_bitstream/parity_checker.sbit`。

## 二、开关与灯

| 板载 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| 开关 SW6（最右） | `G13` | `A` | 数据位 A |
| 开关 SW5 | `H14` | `B` | 数据位 B |
| 开关 SW4 | `H13` | `C0` | 数据位 C0 |
| LED7 | `K18` | `S` | 奇校验位 |
| LED8（最右） | `N15` | `C1` | 偶校验位 |

## 三、操作与现象

S 是三位输入中"1 的个数为奇数"的指示，C1 是"1 的个数为偶数"的指示，两者恒互补——**任何时候两颗灯里必有一颗亮、一颗灭**。

| A | B | C0 | 1 的个数 | S（LED7） | C1（LED8） |
|:---:|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 | 0 | 0（偶） | 灭 | **亮** |
| 0 | 0 | 1 | 1（奇） | **亮** | 灭 |
| 0 | 1 | 0 | 1（奇） | **亮** | 灭 |
| 0 | 1 | 1 | 2（偶） | 灭 | **亮** |
| 1 | 0 | 0 | 1（奇） | **亮** | 灭 |
| 1 | 0 | 1 | 2（偶） | 灭 | **亮** |
| 1 | 1 | 0 | 2（偶） | 灭 | **亮** |
| 1 | 1 | 1 | 3（奇） | **亮** | 灭 |

## 四、验证清单

- [ ] 上电（三开关全 0）：LED8 亮、LED7 灭
- [ ] 逐个拨动任一开关，每次只有一颗灯状态翻转
- [ ] 任意时刻两颗灯**不会同时亮或同时灭**

> 最后一条是最有用的判据。代码里两个译码器的使能必须互补（`G1 = C0`、`G2 = /C0`）；如果两颗灯同时亮，说明使能接错，译码器 1 在 C0=1 时仍在输出。

## 五、注意

- 译码器输出是低电平有效，代码里用与非门对最小项取反，属正常接法。
- 无时钟、无复位，上电即工作。
