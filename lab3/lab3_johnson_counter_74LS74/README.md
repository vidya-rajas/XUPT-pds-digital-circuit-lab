# lab3_johnson_counter_74LS74

**4 位扭环计数器 / Johnson counter（74LS74 + 74LS02）**

- Device: Pango Logos **PGL22G** / speed grade **-6** / package **MBG324**
- Top module: `johnson_counter`
- Project file: `lab3_johnson_counter_74LS74.pds`

## 端口与引脚

| Port | Dir | Pin | 说明 |
|------|-----|-----|------|
| rst | input | K15 | 开关 1（最左）：高电平清零 |
| exclk | input | H18 | **27MHz 全局时钟**（不是开关） |
| q0 | output | N15 | LED 8（最右） |
| q1 | output | K18 | LED 7 |
| q2 | output | J16 | LED 6 |
| q3 | output | H16 | LED 5 |
| clkout | output | F14 | LED 1（最左）：**时钟指示**，1 秒翻转一次 |

板子上开关从左到右：`K15 J14 J15 H13 H14 G13`
LED 从左到右：`F14 F13 F16 G16 H16 J16 K18 N15`

## 时钟

课程要求：**时序电路的时钟不能由普通 I/O 口输入，必须用全局时钟管脚**。

板上全局时钟：27MHz（H18）、50MHz（J18）。本工程用 H18 的 27MHz，
顶层一个 24 位计数器把它分频：

```
cnt 计到 13499999 就翻转一次 clk  →  0.5 秒翻转一次  →  1Hz
```

所以计数器是**每秒自动前进一格**，不需要手动拨时钟。
想快一点就把 13499999 改成 6750000（2Hz），慢一点就改大。

分频出来的时钟另外接到 `clkout`（F14 那颗灯，最左边）上：**这颗灯亮 0.5 秒、灭 0.5 秒，
一秒一个完整周期**。它就是节拍器——74LS74 是上升沿触发，所以**每次这颗灯由灭转亮，
q3~q0 就前进一格**；灯亮灭一次（1 秒）正好对应计数一步。

## 原理

扭环计数器（twisted-ring counter，也叫 Johnson 计数器）就是把移位寄存器的
**末级取反后接回第一级**：

```
D0 = Q3'      D1 = Q0      D2 = Q1      D3 = Q2
```

4 个 D 触发器串成一条链，每来一个时钟整体右移一位，最左边补 Q3 的反。
因为"扭"着接回去，N 个触发器能循环 2N 个状态（普通环形计数器只能循环 N 个）。

## 状态序列

从全 0 开始，每秒变一次：

| 时钟 | q3 q2 q1 q0 | LED 效果 |
|------|-------------|----------|
| 复位 | 0 0 0 0 | 全灭 |
| 1 | 0 0 0 1 | 最右亮 |
| 2 | 0 0 1 1 | 两盏 |
| 3 | 0 1 1 1 | 三盏 |
| 4 | 1 1 1 1 | 全亮 |
| 5 | 1 1 1 0 | 最左灭 |
| 6 | 1 1 0 0 | 两盏 |
| 7 | 1 0 0 0 | 一盏 |
| 8 | 0 0 0 0 | 回到起点 |

看起来就是"从右往左逐盏点亮，再从左往右逐盏熄灭"，8 秒一个循环。

## 门电路怎么分配

| 器件 | 用途 |
|------|------|
| `gate74LS74` U_FF1 | Q0、Q1 两个 D 触发器 |
| `gate74LS74` U_FF2 | Q2、Q3 两个 D 触发器 |
| `gate74LS02` U_NOR | 两路或非门当反相器：Q3'（反馈用）和 rst'（复位反相） |

两片 74LS74 正好 4 个 D 触发器；一片 74LS02 的四个或非门只用了两个，
另外两个输入接 0、输出空着。

## 操作步骤

1. 上电后计数器自动从 0000 开始每秒前进一格，插上就能看。
2. `rst` 拨到 1：四个灯全灭并停住（分频计数器也一起归零）。
3. `rst` 拨回 0：重新从 0000 开始循环。
