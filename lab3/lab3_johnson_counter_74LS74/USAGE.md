# lab3_johnson_counter_74LS74 实验使用说明

四位扭环（约翰逊）计数器：27MHz 先分频到 1Hz 作为节拍，再驱动两片 74LS74 组成的扭环计数器。

- 工程文件：`lab3_johnson_counter_74LS74.pds`
- 顶层模块：`johnson_counter`（源码 `rtl/johnson_counter.v`，门模型 `rtl/gate74LS02.v`、`rtl/gate74LS74.v`）
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. 打开 PDS → File → Open Project → 选本目录的 `lab3_johnson_counter_74LS74.pds`。
2. Design Flow：Compile → Synthesize → Device Map → Place & Route → Generate Bitstream。
3. 下载 `generate_bitstream/johnson_counter.sbit`。

## 二、开关与灯

| 板载 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| 时钟 27MHz | `H18` | `exclk` | 全局时钟输入（**不是开关**） |
| 开关 SW1（最左） | `K15` | `rst` | 复位，置 1 清零 |
| LED1（最左） | `F14` | `clkout` | 1Hz 节拍指示，应持续闪烁 |
| LED5 | `H16` | `q3` | 计数输出最高位 |
| LED6 | `J16` | `q2` | 计数输出 |
| LED7 | `K18` | `q1` | 计数输出 |
| LED8（最右） | `N15` | `q0` | 计数输出最低位 |

## 三、操作与现象

**上电后最左边的 LED（F14）以 1Hz 闪烁**（亮 0.5 秒、灭 0.5 秒）。这颗灯是节拍指示：它每闪一次，`q3~q0` 就变一次状态。

扭环计数器 8 个状态循环，每状态保持 1 秒，整圈 8 秒：

| 节拍 | q3 q2 q1 q0（LED5~LED8） | 十进制 |
|:---:|:---:|:---:|
| 0 | 灭 灭 灭 灭 | 0 |
| 1 | 灭 灭 灭 亮 | 1 |
| 2 | 灭 灭 亮 亮 | 3 |
| 3 | 灭 亮 亮 亮 | 7 |
| 4 | 亮 亮 亮 亮 | 15 |
| 5 | 亮 亮 亮 灭 | 14 |
| 6 | 亮 亮 灭 灭 | 12 |
| 7 | 亮 灭 灭 灭 | 8 |
| 8 | 回到 0 | 0 |

特征：**灯是从右往左逐个点亮，全亮后又从左往右逐个熄灭**，像一条来回扫描的光带。四颗灯永远不会出现"对角线"式的跳变。

## 四、验证清单

- [ ] 最左的 LED（F14）以约 1Hz 稳定闪烁
- [ ] `q3~q0` 每秒变化一次，8 秒一循环
- [ ] 亮灯个数按 0→1→2→3→4→3→2→1 变化
- [ ] `rst`（SW1）置 1 → 全部数据灯灭、F14 也灭；松手后从全灭重新开始

## 五、注意

- 节拍时钟由 27MHz 分频得到：`cnt` 计到 13499999 翻转一次，得到 27M ÷ 27M = 1Hz。
- 该 1Hz 时钟由一个内部寄存器驱动，不是从专用时钟脚来的，PDS 可能给出"非专用时钟"提示，属预期现象。
- 若 F14 不闪而是一直亮/一直灭，先检查 `rst` 是否被拨在 1。
