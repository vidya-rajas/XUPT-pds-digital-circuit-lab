# lab3_serial_comparator_74LS112 实验使用说明

串行数值比较器（讲义图 2-36）：74LS112 双 J-K 触发器 + 74LS02 或非门 + 74LS20 与非门。
逐位比较两个数，把"大于/小于"结果**锁存**在触发器里，相等则两灯都不亮。

- 工程文件：`lab3_serial_comparator_74LS112.pds`
- 顶层模块：`serial_comparator`（源码 `rtl/serial_comparator.v`，门模型 `rtl/gate74LS02.v`、`rtl/gate74LS112.v`、`rtl/gate74LS20.v`）
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. 打开 PDS → File → Open Project → 选本目录的 `lab3_serial_comparator_74LS112.pds`。
2. Design Flow：Compile → Synthesize → Device Map → Place & Route → Generate Bitstream。
3. 下载 `generate_bitstream/serial_comparator.sbit`。

## 二、开关与灯

| 板载 | 引脚 | 信号 | 含义 |
|------|------|------|------|
| 开关 SW1（最左） | `K15` | `a` | 比较输入 a |
| 开关 SW2 | `J14` | `b` | 比较输入 b |
| 开关 SW3 | `J15` | `cp` | **时钟脉冲**，拨动一次产生一个下降沿 |
| 开关 SW4 | `H13` | `rst` | 复位，置 1 清零 |
| LED1（最左） | `F14` | `cpled` | 时钟指示，跟随 `cp`，仅用于观察 |
| LED6 | `J16` | `e` | 相等指示 |
| LED7 | `K18` | `l` | 小于（a < b） |
| LED8（最右） | `N15` | `g` | 大于（a > b） |

## 三、操作步骤

74LS112 是**下降沿**触发，所以每一步都要拨动 `cp` 开关产生一个下降沿：

1. **复位**：`rst`（SW4）拨到 1，此时 g、l 清零，e 亮（表示"相等"）。
2. `rst` 拨回 0。
3. **给数据**：按需要设置 `a`（SW1）和 `b`（SW2）。
4. **打一拍**：`cp`（SW3）拨到 1 —— 再拨回 0。**下降沿发生的瞬间**，比较结果被锁存。
5. 看 LED8 / LED7 / LED6。

## 四、现象对照

| a | b | 锁存后 g（LED8） | l（LED7） | e（LED6） |
|:---:|:---:|:---:|:---:|:---:|
| 0 | 0 | 灭 | 灭 | **亮** |
| 1 | 0 | **亮** | 灭 | 灭 |
| 0 | 1 | 灭 | **亮** | 灭 |
| 1 | 1 | 灭 | 灭 | **亮** |

**结果会保持**：一旦锁存了"a > b"，之后即使把 a、b 改成别的值，只要不复位，LED8 依然亮着——这正是"串行"比较器逐位累积判断的含义。

## 五、验证清单

- [ ] 复位后：仅 LED6 亮（相等）
- [ ] a=1,b=0 打一拍 → LED8 亮
- [ ] 不复位，改成 a=0,b=1 打一拍 → LED8 仍亮（结果锁定，不被覆盖）
- [ ] 复位后 a=0,b=1 打一拍 → LED7 亮
- [ ] 拨动 `cp` 时 F14（cpled）同步亮灭

## 六、注意

- **`cp` 是手动时钟**，接在普通开关上，不是全局时钟脚。PDS 布线时会给出"时钟源不在专用脚"的提示（`Place-2028`，提示级，不影响生成比特流），这是本实验的固有情况。
- `rst` 接在 `H13`，该引脚是**共享脚**，PDS 会提示 `ConstraintEditor-2002`，同样不影响使用；但**不要**把它当时钟用。
- 触发器 J 端接比较结果、K 端接 0，所以只会"置位"不会"清零"，必须靠 `rst` 清除。
