# lab5_5.12.7_traffic_light 使用说明

交通灯控制器：主/次干道交替放行，6 颗灯显示红黄绿，4 位数码管显示两侧倒计时。

## 上板

1. 打开 `lab5_5.12.7_traffic_light.pds` → Compile → … → Generate Bitstream
2. 下载 `generate_bitstream/traffic_light.sbit`

## 灯与开关

| 板载 | 引脚 | 含义 |
|---|---|---|
| LED1 / LED2 / LED3 | `F14` `F13` `F16` | 主干道 红 / 黄 / 绿 |
| LED4 / LED5 / LED6 | `G16` `H16` `J16` | 次干道 红 / 黄 / 绿 |
| SW1 SW2 | `K15` `J14` | 绿灯时长：00=15s、01=20s、10=30s、11=45s |

## 正常现象（以 20 秒档为例）

| 时间 | 主干道 | 次干道 | 数码管 |
|---|---|---|---|
| 0~20s | 绿 | 红 | 主 20→1，次 25→6 |
| 20~25s | 黄 | 红 | 主 5→1，次 5→1 |
| 25~45s | 红 | 绿 | 主 25→6，次 20→1 |
| 45~50s | 红 | 黄 | 主 5→1，次 5→1 |
| 循环 | | | |

任何时刻：**主干道只有一个灯亮，次干道也只有一个灯亮，且两者不会同时绿**。

## 验证

- [ ] 上电后 主干道绿灯、次干道红灯，两侧数字同时倒数
- [ ] 主干道绿→黄→红，切换瞬间次干道由红转绿
- [ ] 黄灯固定 5 秒
- [ ] 主红时间 = 次绿 + 5，次红时间 = 主绿 + 5
- [ ] 拨 SW1/SW2 改档位，周期随之改变（需复位或等下一轮生效）

## 注意

- 绿灯时长是 4 档预设，不是 0~99 任意值（板载开关只有 2 个空闲）。
- 数字到 00 才切换，切换瞬间不会出现两绿。
