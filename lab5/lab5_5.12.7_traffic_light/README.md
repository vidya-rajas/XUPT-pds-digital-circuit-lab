# lab5_5.12.7_traffic_light

**交通灯控制器**（第 5 次实验 5.12.7 节）：主/次干道交替通行，绿灯时间可选，黄灯 5 秒，
两侧各用 2 位数码管倒计时。

- Top module: `traffic_light`　｜　工程：`lab5_5.12.7_traffic_light.pds`
- 器件：PGL22G / -6 / MBG324，`LVCMOS33`（VCCIO 3.3V）

## 引脚

| Port | 含义 | Pin |
|---|---|---|
| `clk` | 50MHz → 1Hz | `J18` |
| `ts1` `ts0` | 绿灯时长选择 | `K15` `J14` |
| `mr` `my` `mg` | 主干道 红/黄/绿 | `F14` `F13` `F16` |
| `sr` `sy` `sg` | 次干道 红/黄/绿 | `G16` `H16` `J16` |
| DIG1~DIG2 | 主干道倒计时（十位、个位） | `M16` `K17` |
| DIG3~DIG4 | 次干道倒计时 | `N17` `N18` |
| 段 A~G/DP | 数码管 | `M14` `N15` `J17` `L17` `L16` `M13` `H17` / `L18` |

## 绿灯时长选择

| ts1 ts0 | 绿灯（主/次相同） | 黄灯 |
|:---:|---|---|
| 0 0 | 15 秒 | 5 秒 |
| 0 1 | 20 秒 | 5 秒 |
| 1 0 | 30 秒 | 5 秒 |
| 1 1 | 45 秒 | 5 秒 |

板载只有 2 个空闲开关，所以改成"4 档预设"，而不是题目要求的 0~99 秒任意设置。

## 状态机（4 态循环）

| 态 | 主干道 | 次干道 | 时长 |
|:--:|---|---|---|
| 0 | 绿 | 红 | T1（绿灯时长） |
| 1 | 黄 | 红 | 5 秒 |
| 2 | 红 | 绿 | T3 = T1 |
| 3 | 红 | 黄 | 5 秒 |

满足题目要求：主红时长 = 次绿 + 次黄；次红时长 = 主绿 + 主黄。

## 显示

- DIG1~2：主干道"距离下次变灯"的秒数；
- DIG3~4：次干道"距离下次变灯"的秒数；
- 两侧同时倒计时，主干道绿灯时次干道在数自己的红灯时间。

## 设计逻辑

1. 50MHz 分频出 1Hz 时基与 1ms 扫显节拍；
2. `st` 四态循环，`cnt` 从当前态的时长倒数到 0 就进下一态；
3. 灯输出由 `st` 直接译码（同一时刻主次各只有一个灯亮）；
4. 倒计数值按"当前处于哪一侧"换算成各自的剩余秒数，再拆分十位/个位送数码管。

## 与题目的差异

- 绿灯时间：题目 0~99 秒可任意设置，本设计为 4 档预设（开关不足）；
- 黄灯：题目 5~10 秒可设置，本设计固定 5 秒；
- 显示：题目要求每组"两个数码管计时和计数"，本设计 4 位数码管正好一侧两位。
