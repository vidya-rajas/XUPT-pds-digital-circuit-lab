# lab5_5.12.6_call_6way 使用说明

6 路呼叫器：6 个开关当呼叫键，板载按键当"处理完毕"，数码管显示最近谁在呼叫。

## 上板

1. 打开 `lab5_5.12.6_call_6way.pds` → Compile → … → Generate Bitstream
2. 下载 `generate_bitstream/call_6way.sbit`

## 开关与灯

| 板载 | 引脚 | 作用 |
|---|---|---|
| SW1~SW6 | `K15` `J14` `J15` `H13` `H14` `G13` | 1~6 号呼叫键（拨 0→1 算一次） |
| 按键 | `G14` | 处理完毕（清掉当前显示的那一路） |
| LED1~LED6 | `F14` `F13` `F16` `G16` `H16` `J16` | 各路未处理的呼叫 |
| LED7 | `K18` | 报警（常亮 2 秒）/ 超时闪烁 |

## 操作

1. 拨一下 SW3（模拟 3 号呼叫）→ LED3 亮，数码管显示 `3`，LED7 亮 2 秒；
2. 再拨 SW5 → LED5 亮，数码管显示 `5`；
3. 按一下板载按键（G14）→ 显示中那一路的灯灭（其余不受影响）；
4. 第一次呼叫后 60 秒内没人处理，倒计时归零停止，灯仍保持；
5. 剩 5 秒时 LED7 每秒闪一次，共 5 次。

## 验证

- [ ] 拨任一路，对应灯亮、数码管显示该编号、LED7 亮约 2 秒
- [ ] 多次呼叫只保留最近编号显示，但先前各路灯一直亮
- [ ] 按 G14 只清当前显示那一路
- [ ] 剩 5 秒时 LED7 以 1Hz 闪 5 次
- [ ] 全部清完，数码管显示 `0`

## 注意

- 呼叫键是开关：**拨过去再拨回来**才算第二次，按住不放只算一次。
- 板上没蜂鸣器，报警用 LED7 代替。
