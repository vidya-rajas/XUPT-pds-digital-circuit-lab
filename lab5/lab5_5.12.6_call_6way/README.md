# lab5_5.12.6_call_6way

**6 路呼叫器**（第 5 次实验 5.12.6 节）：6 个呼叫键 + 1 个"处理完毕"键，
数码管显示最近一次呼叫者的编号，每个未处理的呼叫各亮一颗灯。

- Top module: `call_6way`　｜　工程：`lab5_5.12.6_call_6way.pds`
- 器件：PGL22G / -6 / MBG324，`LVCMOS33`（VCCIO 3.3V）

## 引脚

| Port | 含义 | Pin |
|---|---|---|
| `clk` | 50MHz | `J18` |
| `k1`~`k6` | 1~6 号呼叫键（开关，边沿触发） | `K15` `J14` `J15` `H13` `H14` `G13` |
| `ack` | 处理完毕（瞬时按键） | `G14` |
| `led1`~`led6` | 各路呼叫指示 | `F14` `F13` `F16` `G16` `H16` `J16` |
| `alarm` | 报警/超时提示 | `K18`（LED7） |
| 数码管 | 最近呼叫者编号 | 段 `M14 N15 J17 L17 L16 M13 H17`，位选 `M16 K17 N17 N18` |

**板上只有 1 个瞬时按键**，所以 6 路呼叫用 6 个拨码开关代替（拨 0→1 算按一次），
`ack` 用板载按键 G14。

## 现象

| 操作 | 现象 |
|---|---|
| 按 3 号呼叫 | LED3 亮，数码管显示 `3`，LED7 亮 **2 秒**（报警） |
| 再按 5 号呼叫 | LED5 也亮，数码管变 `5`（最近一次），LED7 再亮 2 秒 |
| 按"处理完毕" | 数码管当前编号那一路的灯灭，数码管保持显示该编号 |
| 首次呼叫后 60 秒 | 到 0 停止倒计时（超时） |
| 倒计时剩 ≤5 秒 | LED7 以 **1Hz 闪烁**，共闪 5 次 |

## 设计逻辑

1. **消抖**：50MHz→1ms 节拍，每路输入 4 位移位寄存器，连续 4 次相同才认，锁存后只在 0→1 出一个单周期脉冲；
2. **呼叫登记**：6 位 `pend` 每位对应一路，脉冲置位；`last` 记录最近一次呼叫的编号；
3. **应答清除**：`ack` 脉冲把 `last` 对应那一位清掉；全部清完则 `last=0`、倒计时停止；
4. **倒计时**：第一次呼叫启动 60 秒倒计时，`cd` 每秒减 1，到 0 停止；
5. **报警/闪烁**：报警用 2 秒定时器（2000 个 1ms 脉冲）；`cd≤5` 时用 1Hz 节拍（`bs[9]`）闪烁；
6. **编号译码**：0~6 直接查段码表，显示在 DIG1，其余位关掉。

## 局限

题目要 1~6 路呼叫、超时闪烁、报警音。板上没有蜂鸣器，**报警用 LED 代替**；
6 路呼叫键用开关模拟（拨过去再拨回来才算第二次）。
