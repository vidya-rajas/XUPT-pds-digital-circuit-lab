# lab5_5.12.4_freq_meter 使用说明

4 位频率计：把被测信号接到 H14，拨两个开关选闸门，数码管直接读 kHz。

## 上板

1. 打开 `lab5_5.12.4_freq_meter.pds` → Compile → … → Generate Bitstream
2. 下载 `generate_bitstream/freq_meter.sbit`
3. 把被测信号（0~3.3V 方波/脉冲）接到 **H14**，地与板子共地

## 开关

| 板载 | 引脚 | 作用 |
|---|---|---|
| SW1 | `K15` | `g1`（闸门高位） |
| SW2 | `J14` | `g0`（闸门低位） |

| g1 g0 | 闸门 | 适用频率 |
|:---:|---|---|
| 0 0 | 1ms | 1kHz ~ 9.999MHz |
| 0 1 | 10ms | 100Hz ~ 999.9kHz |
| 1 0 | 100ms | 10Hz ~ 99.99kHz |
| 1 1 | 1s | 1Hz ~ 9999Hz |

## 读数

- 显示单位固定 **kHz**，小数点位置随闸门自动移动；
- 四位全显示 `-` = 超量程，换更大的闸门（高频）或更小的闸门（低频）；
- 显示每 2 倍闸门时间刷新一次（1s 闸门约 2 秒刷新一次，属正常）。

## 验证

- [ ] 无输入时显示 `0000`
- [ ] 输入 1kHz，闸门 1s → 显示 `1.000` 左右
- [ ] 同一信号换闸门，读数数值不变、只是小数点移动
- [ ] 超量程时四位显示 `-`

## 注意

- `sig` 是 3.3V 电平输入，**不要直接接 5V 信号**，必要时加分压/电平转换。
- 频率高于约 20MHz 时计数开始丢沿（50MHz 基准的极限），本设计不保证 20MHz 以上读数。
