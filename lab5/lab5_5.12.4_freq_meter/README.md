# lab5_5.12.4_freq_meter

**4 位十进制数字频率计**（第 5 次实验 5.12.4 节），测频法：在固定闸门时间内数被测信号的上升沿。

- Top module: `freq_meter`　｜　工程：`lab5_5.12.4_freq_meter.pds`
- 器件：PGL22G / -6 / MBG324，`LVCMOS33`（VCCIO 3.3V）

## 引脚

| Port | 含义 | Pin |
|---|---|---|
| `clk` | 50MHz 基准时钟 | `J18` |
| `sig` | **被测信号输入** | `H14`（SW5 位置，信号从这里进） |
| `g1` `g0` | 闸门选择 | `K15` `J14` |
| 段 A~G / DP | 数码管 | `M14` `N15` `J17` `L17` `L16` `M13` `H17` / `L18` |
| 位选 DIG1~4 | 数码管 | `M16` `K17` `N17` `N18` |

## 闸门与显示

| g1 g0 | 闸门 | 计数值含义 | 显示（kHz） |
|:---:|---|---|---|
| 0 0 | 1ms | 计数值 = f/1000 = **kHz 整数** | `1234` |
| 0 1 | 10ms | 计数值 = kHz×10 | `123.4` |
| 1 0 | 100ms | 计数值 = kHz×100 | `12.34` |
| 1 1 | 1s | 计数值 = f（Hz） | `1.234` |

**小数点自动移动**：闸门越长，小数点越靠左（分辨率越高），这正是题目要求"根据脉冲宽度自动调节小数点位置"。

## 设计逻辑

1. **闸门**：1ms 节拍计数到 `gt`（1/10/100/1000）翻转 `gate`，`gate` 高电平期间为测量窗口；
2. **计数**：`sig` 打一拍取上升沿，`gate` 期间累加 24 位计数器；
3. **锁存**：`gate` 下降沿把计数存入 `lat`，同时清零重新开始 —— 显示值每 2×闸门时间刷新一次；
4. **译码**：`lat` 用"反复减 1000/100/10"转成 4 位十进制（不用除法器）；
5. **溢出**：`lat > 9999` 时四位都显示 `-`，提示换小闸门或超量程。

4 位十进制的上限是 **9999 kHz ≈ 9.999 MHz**；题目写 10MHz，超出 1 个数字，
用 1ms 闸门时 10MHz 会显示 `----`。这是四位数码管的硬限制，已在 README 中说明。

## 拓展（占空比）

**未实现**。原因：占空比要在 1Hz~10MHz 全程准确，必须测"高电平时间/周期"，
需要 32 位宽比较器与除法器；而闸门计数法对 10MHz 信号每周期只有 5 个采样点，
测出来的占空比误差极大。若要做，建议单独加一个"低频占空比"模式。

## 自测方法

把 `sig`（H14）接到一个已知信号源：
- 接 `J18` 的 50MHz → 1ms 闸门显示 `----`（超量程），1s 闸门显示 `----`；
- 接一个 1kHz 方波 → 任一闸门应显示 `1.000` ~ `1.234` 附近的稳定值；
- 没有信号源时 `sig` 悬空/接 0，应显示 `0000`。
