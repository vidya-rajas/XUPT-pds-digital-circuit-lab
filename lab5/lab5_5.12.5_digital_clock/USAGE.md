# lab5_5.12.5_digital_clock 使用说明

24 小时数字钟：4 位数码管，开关切换显示"分:秒"或"时:分"。

## 上板

1. 打开 `lab5_5.12.5_digital_clock.pds` → Compile → … → Generate Bitstream
2. 下载 `generate_bitstream/clock_24h.sbit`

## 开关

| 板载 | 引脚 | 作用 |
|---|---|---|
| SW1 | `K15` | `run`：拨 1 走时，拨 0 停表 |
| SW2 | `J14` | `sel`：拨 0 显示分:秒，拨 1 显示时:分 |
| SW3 | `J15` | `set_h`：**拨住不动**，每过一秒小时 +1 |
| SW4 | `H13` | `set_m`：**拨住不动**，每过一秒分钟 +1 |

## 操作

1. 上电默认 `00:00:00`，`run=1` 后开始走时；
2. 校时：`sel` 拨到 1 看小时，`set_h` 拨住，等到小时数对了再松开；
   再 `sel` 拨回 0 看分钟，用 `set_m` 同样校分；
3. 秒无法单独校，校完分后把 `run` 拨 0 再拨 1，秒从 0 重新开始；
4. 整点（分=00 且 秒=00）时 LED7（K18）亮 1 秒。

## 验证

- [ ] 上电显示 `00:00`（分:秒），拨 run=1 后秒每秒加 1
- [ ] 59→00 进分，59 分 59 秒 → 小时 +1，23:59:59 → 00:00:00
- [ ] `sel=1` 时显示 时:分，数码管第二位小数点亮着
- [ ] `set_h` 拨住，小时按秒递增；`set_m` 同理
- [ ] 整点时 LED7 亮 1 秒

## 注意

- 校时开关是"拨住生效"，不是"拨一下加一"，因为板上没有可靠的按键。
- 板载只有 4 位数码管，时、分、秒不能同时显示，这是硬件限制。
