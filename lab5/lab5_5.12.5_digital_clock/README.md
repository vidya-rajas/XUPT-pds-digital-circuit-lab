# lab5_5.12.5_digital_clock

**24 小时数字钟**（第 5 次实验 5.12.5 节）：时 00~23、分秒 00~59，可运行/停止、单独校时、整点报时。

- Top module: `clock_24h`　｜　工程：`lab5_5.12.5_digital_clock.pds`
- 器件：PGL22G / -6 / MBG324，`LVCMOS33`（VCCIO 3.3V）

## 引脚

| Port | 含义 | Pin |
|---|---|---|
| `clk` | 50MHz → 1Hz 时基 | `J18` |
| `run` | 1=走时，0=停止 | `K15`（SW1） |
| `sel` | 0=显示**分:秒**，1=显示**时:分** | `J14`（SW2） |
| `set_h` | 校时（置 1 时每秒 +1 小时） | `J15`（SW3） |
| `set_m` | 校分（置 1 时每秒 +1 分） | `H13`（SW4） |
| `chime` | 整点报时，高电平有效 | `K18`（LED7） |
| 段/位选 | 数码管 | 见下表 |

段：`M14` `N15` `J17` `L17` `L16` `M13` `H17`，DP=`L18`；位选：`M16` `K17` `N17` `N18`。

## 为什么用一位显示切换

题目的数字钟要同时显示 时:分:秒 共 6 位，板载只有 **4 位**数码管。
按"只显示部分内容"的方案：`sel=0` 显示 **分:秒**，`sel=1` 显示 **时:分**，
用开关切换而不是自动轮播，看哪个都稳定不闪。

## 设计逻辑

1. **时基**：50MHz 计到 24,999,999 得一秒一个单周期脉冲（不是分频方波，避免占空比问题）；
2. **计数链**：秒满 59 进分，分满 59 进时，时满 23 回 0 —— 标准 24 小时循环；
3. **校时**：`set_h=1` 时每个时基脉冲小时 +1；`set_m=1` 时分钟 +1；两者优先级高于正常走时，
   松开开关即回到正常计时（`run=1` 时）；
4. **整点报时**：`min==0 && sec==0` 时把 `chime` 拉高整整一秒；
5. **显示**：`cnt[17:16]` 做位扫描（约 190Hz 刷新），十位用比较链求，个位用"减去十位×10"。
