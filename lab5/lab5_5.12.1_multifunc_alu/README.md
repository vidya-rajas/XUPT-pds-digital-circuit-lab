# lab5_5.12.1_multifunc_alu

**多功能运算电路**（第 5 次实验）

对输入的 1 位二进制数 `A`、`B` 进行比较，按比较结果对 2 位二进制数 `C`、`D` 做相应运算：

| 比较结果 | 运算 | 指示 |
|---|---|---|
| `A > B` | `C + D` | LED1 亮 |
| `A < B` | `C − D` | LED2 亮 |
| `A = B` | `C × D` | LED3 亮 |

结果用一位数码管显示（显示**绝对值**），若为负数则另一颗 LED 亮。

- Device: Pango Logos **PGL22G** / speed grade **-6** / package **MBG324**
- Top module: `multifunc_alu`
- Project file: `lab5_5.12.1_multifunc_alu.pds`
- 芯片：74LS283 ×5

## 设计说明

### 一、比较 A 与 B

```
GT = A · ~B
LT = ~A · B
EQ = ~(GT | LT)
```

三者互斥且穷尽，正好一一对应三种运算。

### 二、运算范围

`C`、`D` 都是 2 位，取值 0～3：

| 运算 | 范围 |
|---|---|
| `C + D` | 0 ～ 6 |
| `C − D` | −3 ～ +3 |
| `C × D` | 0 ～ 9 |

一位数码管能显示的绝对值最大是 9，正好覆盖。

### 三、加法、减法、求绝对值（3 片 283）

| 芯片 | 接法 | 输出 |
|---|---|---|
| `U_SUM` | A=C，B=D，C0=0 | `sum = C + D` |
| `U_DIF` | A=C，B=**~D**，C0=1 | `dif = C − D`（4 位补码） |
| `U_ABS` | A=**~dif**，B=0，C0=1 | `mag = 16 − dif = \|C−D\|` |

减法是补码运算：`C − D = C + ~D + 1`。当 `C < D` 时结果为负，`dif` 的最高位就是符号位：

```
neg = dif[3]
```

此时 `dif` 的值是 `16 − (D−C)`，再求一次补码（`U_ABS`：`~dif + 1`）就得到绝对值。
当 `C ≥ D` 时 `neg = 0`，直接取 `dif`。

### 四、乘法（2 片 283）

```
p0 = c0·d0
n1 = c1·d0     n2 = c0·d1     n3 = c1·d1
```

- `U_M1`：`n2 + n1` → 和为 `p1`，进位 `carry1`
- `U_M2`：`carry1 + n3` → 和为 `p2`，进位 `p3`

乘积 `= p3 p2 p1 p0`，最大 `3×3 = 9`。

### 五、结果选择

```
res = GT ? sum : (EQ ? prod : (neg ? mag : dif))
```

减法分支里再用 `neg` 选一次：负数取绝对值，正数直接取差。

### 六、指示与显示

- `led_add / led_sub / led_mul` 直接由 `GT / LT / EQ` 驱动；
- `sign = LT · neg`，只有"做减法且结果为负"时才亮；
- 七段译码按 `res` 查 0～9 的表，输出取反（数码管是共阳的，段输入低电平点亮）。

### 七、关于实现层次

运算部分（加法、减法、求补、乘法）全部用 **74LS283 实例**实现，符合"用 74LS283 和门电路"的要求。
比较、三选一、七段译码用的是行为级 `assign` / `case`——和本仓库 `lab2_multiplier_2x2_74LS283`
以及 `lab4_test` 的写法一致（课程包里没有 74LS48 译码器，也没有 74LS157 数据选择器）。

如果要严格到"每个与门都是 74LS00"，乘法器的三个部分积和比较器的两个与项还需要展开成门级，需要的话可以再改。
