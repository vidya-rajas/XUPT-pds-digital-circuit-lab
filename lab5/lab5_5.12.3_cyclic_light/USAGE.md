# lab5_5.12.3_cyclic_light 实验使用说明

8 路循环彩灯：8 颗灯按"单灯走位 → 双灯往返 → 中心扩展/收缩"三段循环，
2Hz 一步，30 步一轮（15 秒），全自动，无需任何操作。

- 工程文件：`lab5_5.12.3_cyclic_light.pds`
- 顶层模块：`cyclic_light`（源码 `rtl/cyclic_light.v`）
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. PDS → File → Open Project → 选 `lab5_5.12.3_cyclic_light.pds`
2. Compile → Synthesize → Device Map → Place & Route → Generate Bitstream
3. 下载 `generate_bitstream/cyclic_light.sbit`

## 二、接线

只用时钟和 8 颗灯，**不用拨任何开关**：

| 板载 | 引脚 | 信号 |
|------|------|------|
| 时钟 | `J18` | `clk`（50MHz，板载） |
| LED1～LED8 | `F14` `F13` `F16` `G16` `H16` `J16` `K18` `N15` | `led0`～`led7` |

灯从左到右就是 `led0 → led7`。

## 三、看到的现象

下载后灯自动跑，每 0.5 秒变一次，15 秒完整一轮：

| 阶段 | 时间 | 现象 |
|---|---|---|
| ① 单灯 | 0～4 秒 | 只有一颗灯，从左到右走，到最右后回到最左 |
| ② 双灯 | 4～10.5 秒 | 相邻两颗灯，从左走到最右，停一下往回走回最左 |
| ③ 中心扩展 | 10.5～15 秒 | 中间两颗亮 → 最外两颗亮 → 向内收，来回一趟后回中间 |

## 四、验证清单

- [ ] 上电后灯自动跑，不需要动任何开关
- [ ] 第①段：同一时刻只有一颗灯亮，方向是从左到右
- [ ] 第②段：同一时刻两颗相邻灯亮，走到最右会**折返**
- [ ] 第③段：出现"中间两颗亮"和"最外两颗亮"两种对称图案
- [ ] 30 步一轮约 15 秒，然后重复
- [ ] 任何时刻图案都在上表 30 种之内，没有乱码

## 五、注意

- **没有复位键**：要重新看一轮，断电重启或重新下载即可（电路本身无限循环，不需要复位）。
- 想调速度只改源码里一个常数：
  - `24'd12499999` → 2Hz（默认，0.5 秒一步）
  - `24'd4999999` → 5Hz（0.2 秒一步，看着更快）
  - `24'd24999999` → 1Hz（1 秒一步，慢速观察每一帧）
- 图案全部集中在 `case (step)` 的 30 行里，要改显示花样只改这几行的 8 位码。
