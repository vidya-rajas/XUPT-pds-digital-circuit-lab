# lab5_5.12.3_cyclic_light

**8 路循环彩灯**（第 5 次实验 5.12.3 节）

8 颗 LED 排成一行，按"单灯走位 → 双灯往返 → 中心向两端扩展再收缩"三段循环显示，
每段自动衔接，**上电即自动运行，不需要任何操作**。

- Device: Pango Logos **PGL22G** / speed grade **-6** / package **MBG324**
- Top module: `cyclic_light`
- Project file: `lab5_5.12.3_cyclic_light.pds`

## 设计逻辑

### 核心思路：把显示状态存成"表"（ROM）

题目提示里最关键的一句是"**将显示的状态存入存储器，根据时钟发生程序数据经驱动后送 LED 显示**"。
本设计正是这么做的：

```
        50MHz ──► 分频(2Hz) ──► 步进计数器 step(0~29) ──► 查表 pat ──► 8 颗 LED
```

- `step` 是一个 0~29 的循环计数器，**它只记"第几步"，不关心图案**；
- `pat` 是一张 30 项的查找表（`case` 语句），每项就是一个 8 位显示码；
- 输出 `led0..led7` 直接取 `pat` 的各位。

这样做的好处：**改图案只改表，不动电路结构**。题目给的图 5.72 如果与上表有出入，
只需要把 `case` 里对应的 8 位码改掉，其它逻辑一行都不用动。

### 为什么不用移位寄存器直接实现

题目也提醒："**LED 的显示存在相同的状态，因此不能将移位寄存器的输出状态用作控制电路的输入**"。
本设计里第②段末尾和第③段开头都出现 `○○●●○○○○`（步 10/18/21/29），
同一个图案在不同阶段含义不同。如果拿移位寄存器输出当控制信号，就会在这些重复状态上判错阶段。
用"步进计数器 + 查表"就没有这个问题：阶段由 `step` 的区间决定，和图案无关。

### 时钟分频

50MHz ÷ 2 ÷ 12,500,000 = **2Hz**（`cnt` 数到 12,499,999 翻转一次 `cp`）。
步进计数器直接以 `cp` 为时钟（`always @(posedge cp)`），每 0.5 秒走一步。

想快/想慢只改 `24'd12499999` 这一个常数：
- 5Hz：`24'd4999999`
- 1Hz：`24'd24999999`
