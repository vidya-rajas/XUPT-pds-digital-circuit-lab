# lab5_5.12.8_quiz_buzzer

**多路抢答器**（第 5 次实验 5.12.8 节）：6 名选手抢答，主持人一键开始/复位，
数码管显示抢到的选手号，4 颗灯显示 10 秒倒计时。

- Top module: `quiz_6way`　｜　工程：`lab5_5.12.8_quiz_buzzer.pds`
- 器件：PGL22G / -6 / MBG324，`LVCMOS33`（VCCIO 3.3V）

## 引脚

| Port | 含义 | Pin |
|---|---|---|
| `clk` | 50MHz | `J18` |
| `k1`~`k6` | 1~6 号选手抢答键（开关） | `K15` `J14` `J15` `H13` `H14` `G13` |
| `host` | 主持人键：**短按开始 / 长按≥1.5s 复位** | `G14` |
| `led1`~`led4` | 倒计时条 + 5 秒内闪烁 | `F14` `F13` `F16` `G16` |
| DIG1 | 抢到的选手号（0=无人） | `M16` |
| DIG4 | 倒计时秒数 | `N18` |
| 段 | 数码管 | `M14` `N15` `J17` `L17` `L16` `M13` `H17` |

## 引脚不够的取舍

题目要 8 名选手 + 主持人开始/复位两个键，共 10 个输入；板载只有 6 个开关 + 1 个按键。
按确认的方案改为 **6 路**，主持人两个功能合并到一个按键上：

- **短按（<1.5 秒松开）** = 开始抢答；
- **长按（按住 ≥1.5 秒）** = 复位（同时清零选手号和倒计时）。

## 现象

| 操作 | 现象 |
|---|---|
| 短按 G14 | 4 颗灯亮起（10 秒），DIG4 显示倒计时 |
| 抢答成功（如 3 号） | DIG1 显示 `3`，倒计时停止，4 颗灯常亮 2 秒后熄灭 |
| 无人抢答 10 秒 | 倒计时归零，灯全灭，DIG1 仍为 0 |
| 剩 5 秒内 | 4 颗灯以 1Hz 闪烁 |
| 长按 G14 | 全部清零，回到待命 |

## 设计逻辑

1. **消抖**：1ms 采样 + 4 次连续相同才认，输出单周期脉冲；
2. **主持键长短按**：`hold` 计按住时长（单位 ms），≥1500 触发复位；同时用边沿脉冲触发"开始"；
3. **抢答优先**：`armed` 期间扫描 6 路，**同一拍里编号小的优先**（`if/else if` 链），
   抢到即锁存 `win`、`armed=0`，后续按键全部无效 —— 这就是抢答器的"互锁"；
4. **倒计时**：从 10 秒开始，`armed` 时每秒减 1，到 0 自动解除；
5. **灯条**：按剩余秒数分 4 档（≥8 / ≥6 / ≥3 / ≥1），≤5 秒时叠加 1Hz 闪烁。

## 与原题的差异

- 8 路 → **6 路**（板载输入不够）；
- 主持人"开始"和"复位"合并为一个按键（短按/长按区分）；
- 题目中的 74LS148 优先编码器、74LS373 锁存器、74LS248 译码器在 FPGA 内由逻辑等效实现
  （没有对应的门级模型，且这些功能就是"优先级判断 + 锁存 + 段码译码"，本设计逐项实现）。
