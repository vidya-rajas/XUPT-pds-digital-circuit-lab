# lab5_5.12.2_tug_of_war

**拔河游戏机**（第 5 次实验 5.12.2 节）

7 颗 LED 排成一行，开机时只有中间一颗亮（拔河中心线）。双方各按一次"按键"，
点亮的 LED 就向自己一侧移动一格；先移到自己最外侧的一方获胜，此后双方按键失效、
显示保持。复位键把灯送回中间。

- Device: Pango Logos **PGL22G** / speed grade **-6** / package **MBG324**
- Top module: `tug_of_war`
- Project file: `lab5_5.12.2_tug_of_war.pds`

## 与题目的两处硬件适配

| 题目要求 | 本板实际情况 | 处理 |
|---|---|---|
| 9 个 LED | 板载只有 8 颗 LED | 取奇数 **7 颗**（中心 1 + 左右各 3），否则没有中心线 |
| 3 个按键（A、B、复位） | 板载只有 1 个瞬时按键 `G14` | 改用 3 个拨码开关做**边沿检测**：每拨一次算按一次 |

边沿检测的效果和按键等价：开关从 0 拨到 1 产生一个单拍脉冲，配合 4 ms 消抖，
抖动不会重复计数。把开关**拨回 0 再拨到 1** 才算第二次按键。

## 引脚

### 输入（4 个）

| Port | 含义 | Pin |
|------|------|-----|
| `clk` | 50MHz 全局时钟 | `J18` |
| `btn_a` | A 方"按键" | `K15`（SW1） |
| `btn_b` | B 方"按键" | `J14`（SW2） |
| `btn_rst` | 复位（回到中心） | `J15`（SW3） |

### 输出：拔河 LED（7 颗）

| Port | 位置 | Pin | 灯位 |
|------|------|-----|------|
| `led0` | 最左（A 方获胜位） | `F14` | LED1 |
| `led1` | 左 | `F13` | LED2 |
| `led2` | 左 | `F16` | LED3 |
| `led3` | **中心** | `G16` | LED4 |
| `led4` | 右 | `H16` | LED5 |
| `led5` | 右 | `J16` | LED6 |
| `led6` | 最右（B 方获胜位） | `K18` | LED7 |

### 输出：数码管

| 信号 | 引脚 |
|---|---|
| 段 A/B/C/D/E/F/G | `M14` `N15` `J17` `L17` `L16` `M13` `H17` |
| DP | `L18` |
| 位选 DIG1/DIG2/DIG3/DIG4 | `M16` `K17` `N17` `N18` |

## 怎么玩

1. 上电后约 20ms 自动复位：**只有 LED4（中心）亮**，数码管全 0；
2. A 方拨一下 SW1（K15）→ 灯向左移一格；
3. B 方拨一下 SW2（J14）→ 灯向右移一格；
4. 灯到 LED1 → **A 方胜**；到 LED7 → **B 方胜**；双方按键从此无效；
5. 累计 30 次按键后（不管谁领先）比赛也停止；
6. 按复位 SW3（J15）→ 灯回中心、次数清零，开始下一局。

## 数码管显示（两组交替，每 2 秒一轮）

| 时段 | DIG1 | DIG2 | DIG3 | DIG4 |
|---|---|---|---|---|
| 前 1 秒 | A 次数十位 | A 次数个位 | B 次数十位 | B 次数个位 |
| 后 1 秒 | 当前位置 0~6 | 灭 | 灭 | 灭 |

- A/B 次数 0～30，两位数显示；
- 当前位置就是"双向计数器的计数值"（0 最左，3 中心，6 最右）。

## 设计逻辑

### 一、按键消抖

1. 50MHz 分频出 **1ms** 节拍；
2. 每个输入过一个 4 位移位寄存器，在 1ms 节拍上采样；
3. 连续 4 次采样都是 1 才认定"按下"（约 4ms 消抖），并锁存已确认电平；
4. 只在"已确认电平由 0 变 1"的那一拍产生一个**单周期脉冲**，计数器才 +1。

因为用了"已确认电平"锁存，按住不放只算一次；必须先松开（回到全 0）才能再算一次。

### 二、双向计数

用一个 3 位位置计数器 `pos`（初值 3 = 中心）：

```
A 按键：pos ← pos − 1      （向 0 走，A 侧）
B 按键：pos ← pos + 1      （向 6 走，B 侧）
```

题目提示用的是 74LS193 这类双时钟计数器（递增/递减各一个时钟脚），
FPGA 上直接写成同一个 always 块里的 `+1/−1`，行为等价。

若双方同一拍按下，**A 优先**（`else if` 结构），B 的那次不计。

### 三、位置译码（9 颗灯 → 7 颗）

```
led_i = (pos == i)     i = 0..6
```

任一拍只有一颗灯亮，天然互斥、不会出现两颗灯同时亮的中间态。

### 四、胜负判定与锁定

| 事件 | 动作 |
|---|---|
| `pos == 1` 时 A 按键 | pos 变 0，置 `over=1`、`winner=A` |
| `pos == 5` 时 B 按键 | pos 变 6，置 `over=1`、`winner=B` |
| `total == 29` 时再按一次（总数到 30） | 置 `over=1`，不判胜方 |

`over=1` 后所有按键脉冲都被忽略，`pos` 停在原地，**显示自然保持**——这就是"输出保持"，
不需要额外的保持寄存器。

### 五、上电复位

配置完成后 `por` 计数器从 0 数到 `0xFFFFF`（约 21ms @50MHz），这段时间内强制复位，
保证开机一定停在中心 LED。之后 `por` 停住不再变化。

### 六、数码管扫描

- 4 位按 1ms 一位轮流点亮（刷新率 250Hz，看不出闪）；
- 段码低电平有效（共阳管）、位选低电平选通；
- 数值 0～9 查表，`4'hF` 表示该位**全灭**（用于第二时段的空白位）。
