# lab5_5.12.2_tug_of_war 实验使用说明

拔河游戏机：7 颗灯一字排开，中间一颗亮，双方各拨一下自己的开关，灯就往自己这边移一格，
先到头的一方获胜；30 次内没分出胜负也停止。数码管轮流显示双方按键次数和当前位置。

- 工程文件：`lab5_5.12.2_tug_of_war.pds`
- 顶层模块：`tug_of_war`（源码 `rtl/tug_of_war.v`）
- 器件：PGL22G / -6 / MBG324，IO 电平 `LVCMOS33`（VCCIO 3.3V）

## 一、上板步骤

1. PDS → File → Open Project → 选 `lab5_5.12.2_tug_of_war.pds`
2. Compile → Synthesize → Device Map → Place & Route → Generate Bitstream
3. 下载 `generate_bitstream/tug_of_war.sbit`

## 二、开关与显示的对应

| 板载 | 引脚 | 作用 |
|------|------|------|
| SW1（最左） | `K15` | **A 方按键**（拨一下算按一次） |
| SW2 | `J14` | **B 方按键** |
| SW3 | `J15` | **复位**（灯回中心、次数清零） |

| 板载 LED | 引脚 | 含义 |
|---|---|---|
| LED1 | `F14` | 最左，A 方获胜位 |
| LED2 | `F13` | 左 |
| LED3 | `F16` | 左 |
| **LED4** | `G16` | **中心（开局位置）** |
| LED5 | `H16` | 右 |
| LED6 | `J16` | 右 |
| LED7 | `K18` | 最右，B 方获胜位 |

数码管：段 `M14 N15 J17 L17 L16 M13 H17`，位选 `M16 K17 N17 N18`。

## 三、操作步骤

1. **上电**：约 20ms 后只有 LED4 亮，数码管先显示 `00 00`；
2. **A 方**拨 SW1 从 0 到 1 → 灯左移一格；要把开关拨回 0 才能再算下一次；
3. **B 方**拨 SW2 从 0 到 1 → 灯右移一格；
4. 灯到 LED1 → A 胜；到 LED7 → B 胜；之后双方再拨都没反应；
5. **复位**：SW3 拨到 1 再回 0 → 灯回 LED4，次数清零。

## 四、数码管读法

每 2 秒一轮，交替显示两组信息：

| 时段 | DIG1 | DIG2 | DIG3 | DIG4 | 含义 |
|---|---|---|---|---|---|
| 前 1 秒 | A 十位 | A 个位 | B 十位 | B 个位 | 双方按键次数 |
| 后 1 秒 | 位置 0~6 | 灭 | 灭 | 灭 | 当前计数器值 |

位置编号：0 = 最左（A 胜）、3 = 中心、6 = 最右（B 胜）。

例：前 1 秒显示 `0 3 0 2` → A 按了 3 次、B 按了 2 次；后 1 秒显示 `2` → 灯在左数第 3 颗。

## 五、现象对照

| 操作 | 灯 | 数码管（第一时段） |
|---|---|---|
| 上电 | LED4 | `00 00` |
| A 按 1 次 | LED3 | `01 00` |
| A 再按 1 次 | LED2 | `02 00` |
| A 再按 1 次 | LED1，**A 胜** | `03 00` |
| 复位后 B 按 1 次 | LED5 | `00 01` |
| B 再按 2 次 | LED7，**B 胜** | `00 03` |
| 双方合计按到 30 次 | 停在当时位置 | 不加了 |

## 六、验证清单

- [ ] 上电只有 LED4 亮（中点）
- [ ] A 按一次灯左移一格，B 按一次右移一格
- [ ] 一直按 A，第 3 次时到 LED1 并停住，之后 A、B 都无效
- [ ] 一直按 B，第 3 次时到 LED7 并停住
- [ ] 复位后灯回 LED4、次数归零
- [ ] 按住开关不放只算一次（必须松手再拨）
- [ ] 数码管两组信息每 2 秒交替，数字不闪烁
- [ ] 双方合计 30 次时停止（不满 3 次到边也停）

## 七、注意

- **开关要"拨过去再拨回来"**：程序只在 0→1 的跳变沿计数，一直放在 1 不会再增加。
- **A 优先**：如果两人几乎同一瞬间拨，只算 A 的那次。
- 板子只有 8 颗 LED，本工程用奇数 **7 颗**；题目原本要求 9 颗，因为奇数才有"中心线"。
- 数码管是共阳接法（段码低电平点亮、位选低电平选通）；若全灭，先查通电平和位选。
